This is a web application built using only HTML, CSS, and JavaScript to manage customers and deliveries.

Features:
Personal Table: Each employee has their own editable table.
Warning:Please click the save(kaydet) button if you changed anything in the personal table.
Shared Table: There is a read-only table visible to both employees and employers. Data entered into the personal table (e.g., delivery counts) is sent to this shared table after being saved and cannot be modified thereafter. It also displays how many deliveries each employee has made.
Archive: Data from the shared table is transferred to an archive at the end of the day and stored for one month, allowing past activity to be viewed.
Settings: Includes options for font size and color themes; preferences are saved individually for each user.
Employer Account: The employer also has the authority to delete employee accounts and associated records—for instance, in the event of an employee leaving the job—for security purposes.
